# Codex SSH artwork

- `icon.png`: transparent square mark for a skill/plugin icon.
- `banner.png`: larger README header using the same mark and visual language.
- `architecture.svg`: standalone architecture diagram for reuse outside GitHub.

The mark combines terminal brackets, a local server and a connecting tunnel arch.
The palette uses teal and navy. Original artwork in this repository is covered by
the repository's MIT license. The mark is an independent project identity and
does not use OpenAI's or Proxmox's official logos.

The README also renders the topology as a Mermaid diagram with accessible text.
Use the PNG icon as supplied for product image fields; it is not an executable
skill manifest or an automatic plugin registration.
